About WaveCast Live Audio

Pure WebRTC Audio Mesh: Broadcasters stream compressed Opus audio directly to connected clients with sub-50ms peer latency using Web Audio API nodes.

Single Device Testing: Click Single-Device Loopback Demo at the top. This generates a synthetic melodic beat without needing multiple devices.
